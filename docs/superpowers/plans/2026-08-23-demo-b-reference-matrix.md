# Demo B → 生产页面视觉基线矩阵

这份矩阵只记录生产迁移的验收基线，不承载 Demo 的静态数据、角色切换或主题切换逻辑。

## 统一壳层

| 规则 | 生产基线 |
| --- | --- |
| 顶栏 | 66px；品牌、角色/学校、通知、帮助、用户菜单保持同一水平层级 |
| 桌面侧栏 | 232px；白色半透明表面、右边框、40px 导航行、浅苔绿色选中态 |
| 内容区 | 画布 `#F3F4F0`；常规内容最大 1120px；审核/数据宽版最大 1280px |
| 卡片 | 白色表面、1px 浅边框、12px 圆角、克制软阴影 |
| 标题 | Georgia / Songti SC / STSong / SimSun 衬线字体；正文和控件使用系统无衬线字体 |
| 主操作 | 每页只保留一个苔绿色实心按钮；次操作使用白底边框或文字按钮 |
| 状态 | 浅背景胶囊 + 图标 + 文案；不只依赖颜色表达状态 |

| --- | --- | --- | --- |

## 交互检查

- 当前导航只高亮当前职责入口；学生项目工作页不与“我的项目”同时高亮。
- 每个页面同一能力不同时出现在主导航、页面主按钮和重复卡片中。
- 弹窗、通知、帮助、历史对话、AI 工具菜单支持 Escape 关闭，按钮具有可见焦点。
- Tab 使用 `aria-selected` 和 `aria-controls`；开关不被整行链接包裹。
- 390px、768px、1024px、1280px、1440px 不产生文档级横向滚动；长表格只允许局部滚动或转换为卡片。
- AI 无课题流程固定为“发现现象 → 打开问题 → 头脑风暴 → 共同成题”，确认生成前不创建项目。
- 教师 AI 只输出检查建议和评语草稿，最终通过/打回始终由教师操作。
