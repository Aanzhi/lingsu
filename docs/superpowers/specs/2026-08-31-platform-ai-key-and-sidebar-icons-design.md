# 平台 AI Key 配置与学生侧栏图标统一设计

日期：2026-08-31

## 背景与目标

平台设置页当前只能查看 AI 服务是否通过环境变量配置，平台管理员无法在页面录入或替换 API Key。学生工作台侧栏当前存在重复或语义不够明确的图标，折叠按钮也使用普通字符箭头，与导航图标风格不一致。

本次变更目标：

1. 允许平台管理员在平台设置页录入、替换全平台共用的 AI API Key。
2. API Key 保存后，前端永远不能读取原文，只能看到开头 4 个字符、固定星号和结尾 4 个字符。
3. 服务器端能够在 AI 任务执行时读取当前有效 Key，容器重启后配置仍然存在。
4. 统一学生侧栏及展开/收起控制的线性图标风格，并让每个入口具备独立语义。

## 方案与边界

采用数据库加密存储方案，不采用从网页直接修改服务器环境变量的方式，也不扩展为学校级多 Key 配置。

- 配置范围：全平台单例配置，所有学校共用一把 Key。
- 访问范围：只有 `platform_admin` 可以读取配置状态和写入新 Key。
- 前端返回：只返回 `configured`、`masked_key` 等元信息，不返回原始 Key。
- 替换语义：配置页输入框始终为空；输入新 Key 后覆盖旧 Key。页面不提供旧 Key 回显或复制能力。
- 清除语义：本期不提供空值覆盖清除操作，避免误删导致全平台 AI 中断；如需清除，后续可增加明确的二次确认动作。
- 加密密钥：使用部署侧提供的独立 `AI_CONFIG_ENCRYPTION_KEY`，不把解密密钥写入数据库。缺少该配置时，写入接口拒绝保存并返回可操作错误。
- 兼容性：在数据库配置尚未设置时，服务端继续支持现有环境变量作为启动兜底；一旦数据库配置存在，数据库配置优先。

## 后端设计

### 数据模型

新增全局单例配置模型，至少包含：

- `key`: 固定单例标识，建立唯一约束。
- `encrypted_api_key`: 加密后的密文，不序列化给前端。
- `masked_api_key`: 脱敏值，便于展示和避免每次读取都解密；由服务端根据原文生成。
- `updated_at`、`updated_by`：配置变更追踪信息。

模型访问通过一个集中式服务函数完成，避免 views、Celery task 和其他业务代码各自读取环境变量。服务函数提供：

- `get_configured_ai_api_key()`：数据库 Key 优先，无数据库配置时返回环境变量兜底。
- `mask_ai_api_key(value)`：长度大于 8 时保留首尾各 4 位，中间使用固定 8 个 `*`；过短值不返回可推断的原文。
- `save_configured_ai_api_key(value, actor)`：校验非空、加密保存、更新元数据。

### API

新增仅平台管理员可访问的配置端点：

- `GET /api/platform-ai-config/`
  - 返回是否已配置、脱敏 Key、当前模型和 Base URL 等非敏感信息。
  - 禁止返回 `encrypted_api_key`、原始 Key 或包含 Key 的调试字段。
- `PUT /api/platform-ai-config/`
  - 请求体只接受新的 `api_key`。
  - 成功后返回新的脱敏值，不返回原文。
  - 非平台管理员返回 403；缺少加密密钥或输入非法返回 400/503。

AI 可用性接口、同步 AI 入口和 Celery AI 任务统一改用集中式读取函数，确保网页保存的新 Key 立即对新任务生效。已有环境变量行为保持兼容。

### 安全与审计

- 所有日志、异常和审计记录禁止包含原始 Key 或密文。
- 配置接口使用现有 SessionAuthentication、CSRF 和平台管理员权限体系。
- API Key 输入框使用 `type=password`，不使用浏览器自动填充旧值。
- 保存动作只返回脱敏信息；服务状态接口继续只返回 `configured/demo_mode`。

## 前端设计

### 平台设置

在 `PlatformSettings.vue` 新增“AI 服务配置”卡片，放在服务健康区域之前：

- 未配置：显示空密码输入框、说明文字和“保存 Key”按钮。
- 已配置：显示脱敏 Key、配置状态和空密码输入框；按钮文案为“替换 Key”。
- 保存成功：清空输入框，刷新脱敏状态并显示成功反馈。
- 保存失败：保留当前输入，显示可理解的错误反馈，不改变已保存状态。
- 文案明确说明：平台只显示脱敏结果，之后无法查看完整 Key。

### 学生侧栏图标

扩展导航图标注册表，使学生入口不再复用同一内容图标：

- 首页：House
- 我的项目：FolderOpened
- 灵思 AI：MagicStick
- 研究进程：时钟/路线类线性图标
- 项目邀请：User/成员类线性图标
- 案例库：Reading/文档类线性图标
- 赛事信息：Trophy 线性图标
- 校内通知：Bell 线性图标
- 展开/收起：ArrowLeft/ArrowRight 线性图标

所有图标保持同一尺寸、颜色、描边感和 Element Plus 图标来源。折叠状态继续保留 `aria-label` 和 `title`。

## 测试设计

### 后端

- 平台管理员可以读取配置状态，但响应中不出现原始 Key、密文字段或环境变量名。
- 平台管理员保存 Key 后，响应只包含正确的脱敏结果。
- 学生、教师和未登录用户不能读取或写入配置。
- 数据库配置优先于环境变量；没有数据库配置时保留环境变量兜底。
- 缺少 `AI_CONFIG_ENCRYPTION_KEY` 时不会保存明文或半成品配置。
- AI 任务读取集中式配置函数，能使用刚保存的 Key。
- 脱敏函数覆盖正常长度、8 字符及以下、空值和特殊字符场景。

### 前端

- 设置页渲染 AI 配置卡片、密码输入框、状态和替换流程。
- 保存请求发送原始 Key，但响应和后续页面状态只使用脱敏值。
- 学生侧栏每个入口使用预期的唯一图标，展开/收起按钮使用图标组件而非字符箭头。
- 现有设置页、导航和服务状态测试保持通过；更新已过时的页面字符串契约测试。

## 错误处理与迁移

- 数据库迁移创建单例配置表，不迁移现有环境变量内容到数据库，避免部署时意外复制秘密。
- 首次打开页面时只读取配置元信息，不触发解密后端 Key 的返回。
- 如果数据库配置损坏或无法解密，服务端按未配置处理并记录不含秘密的错误；不回退到损坏密文。
- 环境变量兜底仅用于兼容旧部署，文档建议生产环境通过页面保存后再逐步移除环境变量。

## 不在本期范围

- 学校级或用户级多 Key 管理。
- Key 权限分级、轮换历史和撤销历史页面。
- 浏览器端保存 Key、复制 Key 或导出 Key。
- 修改其他角色侧栏的信息架构。
