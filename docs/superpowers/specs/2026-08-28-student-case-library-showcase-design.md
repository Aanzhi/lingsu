# 学生案例库公开成果展厅设计规格

## 产品定位

案例库是学生浏览“已经完成并获得公开授权的研究成果”的地方，不承担项目进度管理，也不承担公开申请表单的主流程。项目公开申请继续保留，但只作为页面右上角的次级工作入口。

## 页面层级

1. 页面标题区：说明这里只展示已完成、审核通过并获得授权的成果。
2. 工具区：一个关键词搜索入口，沿用现有真实筛选行为。
3. 案例区：公开成果卡片。首个成果使用宽卡突出，其余成果使用统一双列卡片。
4. 申请入口：右上角“我的公开申请”，通过现有 `view=applications` 查询参数打开申请管理视图。

## 案例卡信息

卡片只表达成果本身：项目标题、研究问题、公开摘要、学校、研究类型、公开范围、成果形式、已公开材料数量和标签。因为进入案例库的记录已经满足完成与审核条件，不再展示进度条、未完成步骤或“项目已完成并通过审核”的解释提示块。

## 业务边界

- 不改公开案例接口、权限和申请状态机。
- 学生端继续通过现有接口读取公开案例、自己的项目和材料。
- 公开申请继续使用现有弹窗和 `view=applications` 兼容入口。
- 不新增案例详情路由；没有真实行为的“查看”按钮不进入生产页面。

## 验收标准

- 学生案例主视图不出现进度条或完成提示块。
- 案例列表不被前端固定截断为前三条。
- 公开申请入口与案例浏览视觉分层，且仍可进入真实申请管理视图。
- 1280px、1440px 下案例卡无横向溢出。
