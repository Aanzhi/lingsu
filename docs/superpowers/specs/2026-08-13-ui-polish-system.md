# 灵溯 UI 精修基线

## 目标

在不改变暖白北欧研究手帐方向的前提下，消除三端页面的错位、密度失衡和无反馈操作。学生端以当前行动为中心，教师端以审核队列为中心，平台端以授权治理为中心；三端共享同一套排版、间距和状态语义。

## 设计令牌

- 页面背景：象牙白 `#f6f5ef`；内容纸张：`#fffefb`；边界线：`#e2e1d8`。
- 语义色：苔藓绿代表通过和可继续，陶土红代表修订和风险，琥珀代表等待，灰色代表锁定或失效。状态不能只靠颜色，必须同时显示图标与文字。
- 圆角只使用 8、12、16px；主按钮高度 42px；正文 14px，辅助信息 11–12px，页面标题 28–36px。
- 桌面内容区以 40px 上间距、20px 主间距为基线；卡片内部 24–28px，表单与任务编辑纸张可扩展到 34–46px。

## 交互与反馈

- 每个保存、提交、审核、认领、授权变更都必须经历禁用/进行中/成功或失败状态。
- 成功、失败、提示统一使用顶部反馈条；失败保留用户已输入的内容，并在可重试时提供明确的重试动作。
- 任务完成度同时展示：已通过数、总数、百分比、等待审核数和当前任务状态。需修订任务优先于普通待办。
- 列表行和可点击卡片提供低幅度悬浮反馈；不以跳转代替完成反馈。

## 布局规则

- 一级页面固定为：页面标题与说明 → 当前状态/关键指标 → 主工作区。不得重复出现同一标题或同一状态摘要。
- 左右栏仅放上下文与行动，主列放当前任务或当前审核材料；在 1040px 以下按主列、上下文、辅助操作顺序堆叠。
- 780px 以下取消固定侧栏和粘性辅助卡；表格改为可横向查看或压缩为三列，避免内容被挤压或溢出。

## 本轮验收

- 1280px 平台首页和学校详情没有横向溢出，顶栏、侧栏、标题和卡片左边线对齐。
- 学生任务页的附件区不再使用浮动定位，文件项单独占行；提交区域在窄屏下按纵向排列。
- 任务、审核、学校授权的反馈都使用相同的状态、间距和按钮高度。
- 前端类型检查、单元测试和生产构建均通过。

## 交互、状态与信息层级补充

### 已落实

- 所有共享操作按钮统一最小高度、悬浮、键盘焦点和禁用状态；禁用操作会降低不透明度并移除悬浮位移，避免误导用户为仍可点击。
- 表单输入、下拉、长文本和学校授权配置使用同一套聚焦边框与柔和绿色焦点环。真实性确认框支持键盘焦点，并采用 16px 复选框和语义色强调。
- 任务、审核、授权和案例等状态统一为“文字 + 色彩 + 边框”的胶囊标签；标签不再在窄列里被压缩，避免完成状态难辨认。
- 错误提示采用陶土色左边线并保留输入内容；材料行和附件区域的错误提示保持独立垂直节奏，避免与提交控件重叠。
- 已在 1280px 实机检查学生首页、研究地图、任务页、教师审核/项目详情、平台首页/学校详情；均无横向溢出，主列优先于上下文侧栏。

### 仍须按功能推进

- 将后端真实保存、审核、上传失败与异步状态接入现有反馈条，替换目前的演示数据反馈。
- 为复杂列表加入空状态、加载骨架和分页/筛选结果数，避免数据增多后信息密度再次失控。
- 在真实文件上传、报告导出和 AI 请求接入后，补充取消、重试、后台完成通知及失败恢复测试。
