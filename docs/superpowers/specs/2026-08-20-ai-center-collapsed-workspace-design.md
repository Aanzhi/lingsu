# 科创共创中心：折叠式工作台设计

## 目标

将当前同时展示全部 Agent 卡片、表单和历史记录的 AI 中心，调整为聊天优先、按需展开的工作台。学生进入页面时只需要面对一个当前任务，而不是整套工作流。

## 页面结构

### 固定顶栏

- 项目选择器。
- `课题申报`、`论文写作` 两个轨道切换。
- `全部工具` 按钮，打开工具抽屉。
- 历史记录按钮，打开生成记录抽屉。

### 主工作区

- 默认只显示“当前共创”卡：当前 Agent 名称、简短目标、聊天式输入框和生成按钮。
- 初始 Agent 为当前阶段推荐工具；没有任务上下文时为课题名称与摘要。
- 学生可直接以自然语言提问。选择工具后，输入框仍保持聊天形式，但该工具的输入契约字段按需显示在“补充信息”折叠区。
- 生成完成后，在同一工作区显示可编辑草稿、核验项、下一步行动和“保存为材料草稿”。

### 工具抽屉

- 默认关闭。
- 按轨道分组：申报五项工具；论文六项工具。
- 只突出当前阶段可用工具；其他工具仍可选择。
- 论文轨道在抽屉顶部选择论文类型，后续工具沿用该类型。

### 历史抽屉

- 默认关闭；关闭状态仅在顶栏显示最近一次生成的简短状态。
- 打开后展示当前项目的生成记录，点击记录在主工作区打开草稿与核验内容。

## 行为与边界

- 现有 11 个 Agent、结构化产物、材料保存和教师审核链路不改变。
- 当前任务快捷入口直接指定项目、任务和 Agent；打开后只展开对应工具，不展示全量卡片。
- 桌面端可显示窄的阶段进度；移动端改为顶部“阶段”按钮。
- 所有抽屉可通过 Esc 关闭，按钮有清晰的展开状态和键盘焦点。

## 测试

- 默认页面不渲染全量工具卡或完整历史列表。
- 工具、历史抽屉可开关，Agent/论文类型/任务上下文保持正确。
- 输入契约字段、生成、保存材料草稿和教师审核回归通过。
- 桌面与移动断点下不出现横向溢出；键盘可访问。
