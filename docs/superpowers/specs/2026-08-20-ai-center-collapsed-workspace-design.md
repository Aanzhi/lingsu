# 科创共创中心：全局多对话 AI 工作台设计

## 目标

将当前同时展示全部 Agent 卡片、表单和历史记录的 AI 中心，调整为类似 Codex 的全局多对话工作台。对话独立于项目存在，但每个对话绑定一个项目上下文；学生进入页面时面对的是当前对话，而不是整套工作流。

## 核心模型

- AI 工作台是全局入口，Agent 模板也是全局资源。
- 一个对话只绑定一个项目，避免不同项目的材料、数据和教师反馈串线。
- 未绑定项目的对话只允许通用咨询；需要读取项目材料、生成课题/论文草稿时，必须选择项目。
- 项目页的快捷入口创建或打开“该项目 + 该任务 + 该 Agent”的对话，并跳转到对话页面。
- 对话保存消息、选中的 Agent、论文类型、项目上下文快照和生成结果；项目材料仍通过既有材料版本链路保存。

## 页面结构

### 全局布局

- 左侧为对话列表：新建对话、按项目筛选、重命名、归档；显示项目徽标和最近消息摘要。
- 中间为聊天流：用户消息、AI 回复、结构化草稿、核验项和下一步行动都在同一条时间线上。
- 右侧为上下文抽屉，默认关闭；打开后显示当前项目、任务、材料、论文类型和本次对话允许读取的范围。

### 固定顶栏

- 当前对话标题与项目选择器。
- `课题申报`、`论文写作` 两个轨道切换。
- `Agent` 按钮，打开全局工具抽屉。
- `上下文` 按钮，打开项目上下文抽屉。

### 对话主工作区

- 默认显示最近一次对话；没有对话时显示新建对话空状态。
- 输入框支持自然语言、`/` Agent 命令和附件/材料引用；Agent 选择器提供全局 11 个学生工具。
- 选择 Agent 后，输入框仍保持聊天形式，契约字段按需显示在“补充信息”折叠区。
- 生成完成后，结构化草稿、核验项、下一步行动和“保存为材料草稿”作为聊天消息卡片出现。
- 保存材料时必须选择当前项目和目标材料，不自动提交审核。

### Agent 抽屉

- 默认关闭，按 `/` 或点击 `Agent` 打开。
- 按轨道分组：申报五项工具；论文六项工具。
- 显示全局 Agent；根据当前项目类型、阶段和论文类型排序，但不把全部卡片铺在主页面。
- 论文轨道在抽屉顶部选择论文类型，后续工具沿用该类型。

### 上下文抽屉

- 默认关闭；关闭状态只显示项目名称和上下文数量。
- 打开后展示当前项目、任务、材料、论文类型和上下文范围开关。
- 上下文范围由 Agent 契约决定，学生不能扩大到其他项目；一致性 Agent 才允许读取当前项目的跨材料摘要。

## 行为与边界

- 现有 11 个 Agent、结构化产物、材料保存和教师审核链路不改变。
- 当前任务快捷入口直接指定项目、任务和 Agent；打开后进入对应对话，不展示全量卡片。
- 桌面端可显示窄的阶段进度；移动端改为顶部“阶段”按钮。
- 所有抽屉可通过 Esc 关闭，按钮有清晰的展开状态和键盘焦点。

## 数据与接口调整

- 新增对话实体，归属学生和单一项目，可记录标题、论文类型、选中 Agent、归档状态和最近活动时间。
- AI 生成记录关联对话；保留现有项目权限、学校边界、审计和材料版本关联。
- 新增对话列表、创建/归档/重命名和消息历史接口；生成接口接收 conversation、project、agent 和结构化输入。
- 对话上下文只从当前项目读取；切换项目必须新建或切换到该项目的对话，不能在同一对话中混用项目。

## 测试

- 默认页面不渲染全量 Agent 卡片或完整上下文面板。
- 多对话新建、切换、重命名、归档和按项目筛选正常。
- 对话绑定项目后，生成、保存材料和教师审核仍沿用当前权限闭环。
- 工具、历史抽屉可开关，Agent/论文类型/任务上下文保持正确。
- 输入契约字段、生成、保存材料草稿和教师审核回归通过。
- 桌面与移动断点下不出现横向溢出；键盘可访问。
