# 灵思 AI Workbench 项目内重设计规格

## 目标

将学生端 `/student/ai` 重构为项目工作台中的集中式 AI 对话区。页面保留学生端左侧导航，内容采用方案 B 的浅色纸白、苔绿色和系统无衬线体系，借鉴现代 AI 助手的空间关系，但不复制 WorkBuddy 的品牌、机器人、深色主题或宣传文案。

## 页面状态

- 空会话：显示灵思 AI 标题、开题/研究/成果表达模式、动态 Agent 胶囊、当前项目上下文和大 Composer。
- 对话状态：标题收缩为轻量会话栏，消息流占据主画布，Composer 固定在底部。
- 历史抽屉从左侧打开，上下文抽屉从右侧打开，默认关闭，不挤压主画布。
- 开题会话不绑定项目，也不读取材料；研究和成果表达必须绑定当前项目。

## 数据边界

- 保留 `/student/ai`、`mode`、`projectId`、`taskId`、`agent` 和 `researchQuestion`。
- 材料选择使用 ID 数组，并通过 `context_scope.selected_materials` 发送。
- Agent 通过现有 `context_scope_default.allowed_selections` 声明可选上下文。
- 服务端校验项目权限、材料归属、可读取版本和附件安全状态。
- AI 结果只产生对话、草稿或待确认项目数据；保存材料和创建项目均需人工确认。
- 教师 AI 只写入评语草稿，不执行通过或打回。

## 视觉验收

- 66px 顶栏、全屏画布、约 1120px 主内容区。
- 1280px 和 1440px 无文档级横向滚动。
- 用户消息为浅苔绿气泡，AI 消息为正文流，结果卡片轻量化。
- 学生 AI 页面保留通用学生左侧导航，不再嵌套第二套侧栏；主内容使用统一的对话画布、模式切换和 Composer。
